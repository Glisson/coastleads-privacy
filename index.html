CoastLeads Privacy Policy Last updated: May 2026 CoastLeads is a desktop application built for real estate agents to manage Facebook Page posts, track engagement analytics, and organize leads. This privacy policy explains what data the application accesses, how it is stored, and who has access to it. 1. What Data We Access CoastLeads accesses the following data through the Facebook Graph API: Facebook Page posts, captions, and publication dates Post engagement data including reactions, comments, and shares Post reach, impressions, and click metrics (via Pages Insights API) Comments on Page posts (used to identify potential leads) Facebook Lead Ad form submissions (leads_retrieval permission) 2. How Data Is Stored All data accessed by CoastLeads is stored locally on the user's device in a SQLite database file. No data is transmitted to any third-party server operated by CoastLeads. The only outbound network requests made by the application are: To the Facebook Graph API (graph.facebook.com) to retrieve post and engagement data To the Anthropic API (api.anthropic.com) to generate AI-assisted post copy when requested by the user API credentials (Facebook Page Access Token, Anthropic API Key) are encrypted using the operating system's secure storage (macOS Keychain or Windows DPAPI) and are never stored in plain text. 3. Who Has Access CoastLeads is a single-user desktop application. Only the person operating the application on their device has access to the data it stores. No data is shared with other users, third parties, or CoastLeads developers. 4. Data Retention Data is retained on the user's device until they choose to delete the application's database file. There is no automatic data expiration. Users can delete all stored data at any time by deleting the local database file. 5. Facebook Platform Data CoastLeads uses the Facebook Graph API in accordance with Meta's Platform Terms and Developer Policies. Data obtained through the Facebook API is used only to display analytics and manage content for the Page owner's own business purposes. No Facebook data is sold, transferred, or used for advertising purposes. 6. Lead Contact Information Contact information logged in CoastLeads (names, email addresses, phone numbers) is entered manually by the application user or retrieved from Facebook Lead Ad submissions with the user's explicit authorization. This information is stored locally on the user's device and is not transmitted anywhere. 7. Children's Privacy CoastLeads is intended for use by real estate professionals. It is not directed at children under the age of 13 and does not knowingly collect data from children. 8. Changes to This Policy This privacy policy may be updated from time to time. The date at the top of this page reflects the most recent revision. 9. Contact For questions about this privacy policy or data practices, contact: janet.glisson@yahoo.com
